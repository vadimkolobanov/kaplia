# Code of Conduct

Этот проект использует [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Наш стандарт

Создаём окружение, где каждый чувствует себя в безопасности независимо от возраста, гендера, опыта, национальности, внешности, идентичности или ориентации.

**Приветствуется:**
- Эмпатия и доброжелательность
- Конструктивная критика — по коду, не по человеку
- Готовность признать ошибку и извиниться

**Недопустимо:**
- Оскорбления, троллинг, личные нападки
- Харассмент в любой форме
- Публикация чужих личных данных без согласия
