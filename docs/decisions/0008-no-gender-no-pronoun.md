# 0008. Без пола и местоимений — Капля нейтральна

- **Status:** accepted
- **Date:** 2026-06-03
- **Deciders:** @vadimkolobanov
- **Supersedes:** [0004](0004-genderless-character.md)

## Контекст

[ADR-0004](0004-genderless-character.md) сделал Каплю бесполой, но добавил в онбординг шаг выбора местоимения (он / она / они / оно), обязал передавать `pronoun` в каждый LLM-промпт и параметризовать все UI-строки про Каплю.

На практике для тамагочи это лишнее трение: пользователю не нужно «идентифицировать» питомца перед игрой. Капля — это Капля. Шаг выбора местоимения усложняет онбординг и модель без продуктовой ценности.

## Решение

**Капля — существо без пола и без выбора местоимения.**

- В онбординге остаётся только **имя** (шаг выбора местоимения удалён).
- К Капле обращаются **нейтрально** — по имени; в строках избегаем родовых форм.
- Поле `pronoun` удаляется из domain-модели (`Pet`), Room (`KaplaEntity`), UI и event taxonomy (`analytics.md`).
- LLM-промпты пишутся нейтрально, без он/она.

## Последствия

### Позитивные
- Онбординг короче (один шаг — имя), меньше трения до первого контакта.
- Нет параметризации строк по местоимению — проще локализация.
- Меньше полей в модели/БД/промптах.

### Негативные
- Русские строки про Каплю используют нейтральные формулировки (избегаем родовых окончаний) — местами чуть менее естественно.

### Что станет сложнее
- Авторы LLM-промптов должны держать нейтральный тон (без родовых форм).
